# jeekuento.github.io

Hosts the Tesla Fleet API third-party public key for Rocky’s personal app **Personal Charging Mileage** (charging invoices + odometer).

Public key path (required by Tesla):

`https://jeekuento.github.io/.well-known/appspecific/com.tesla.3p.public-key.pem`

Do not add the private key to this repository.
